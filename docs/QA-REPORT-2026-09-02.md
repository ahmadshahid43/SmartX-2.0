## Manual Acceptance Checklist

Run the local stack first:

```powershell
cd "D:\Personal Projects\stitch_omnistack_erp_pos"
& ".\run-demo.cmd"
```

Keep both command windows open, then verify:

1. Open `http://localhost:5163/health`; it must show `Healthy`.
2. Open `http://localhost:4200` and sign in with the local administrator account.
3. Open POS, add a product, select tender and complete a test sale.
4. Confirm stock quantity is reduced in Inventory.
5. Open Customers and confirm the saved customer list is present.
6. Open Reports, use both `Sales register` and `Ledger` switches, search a reference and select `Print report`.
7. In the browser print dialog choose a printer or `Save as PDF`.

## Known QA Limitation / Release Risk

The browser web proxy can remain available while the API is not running. In that state, the browser shows data/API errors even though `http://localhost:4200` itself opens. This is expected local-service behavior, not a data loss issue.

**Recovery:** run `run-demo.cmd` and keep the API command window open. Verify `http://localhost:5163/health` before using the web application.
